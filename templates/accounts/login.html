There is no social auth in the project — no allauth, no OAuth client, no provider settings. Buttons for them would be three dead controls on the one screen a user cannot get past, and the failure would look like the account being broken. - "Forgot password?". There is no public reset flow. change_password and request_password_change_email both require an authenticated session, so the link has nowhere to point for the person who actually needs it. - An "Email" field. authenticate() is called with username, so a field labelled Email would reject the address a customer typed into it. The composition the reference is actually made of — gradient backdrop, one floating card, medallion over a centred title, icon-led fields, full-width CTA — is all here. {% endcomment %} Gerlyn
