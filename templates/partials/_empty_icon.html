{% comment %} The internal system's empty-state art, one copy for every module. Every .empty block used to draw its own character in the 48px circle — □ for "no rows", ＋ for "none created yet", ✓ for an all-clear, ! for a block, ₱ for billing. Five different alphabets, none of them line art, and all of them at the mercy of the viewer's emoji font: □ in particular is literally the glyph a font renders when it has nothing to draw, so the most common empty state in the system was indistinguishable from a broken one. The Scan buttons carried a 📷 for the same reason, which rendered full-colour on Windows and flat on Linux and matched nothing else on the page. These are the same 24x24 / stroke-2 / currentColor drawings as the rest of the internal UI, and six of them are deliberately the SAME paths as partials/_status_icon.html and reports/_row_icon.html rather than new art: box, truck, cart, peso, alert and check-circle. A purchase order is one truck across the Reports tab bar, the status filters and this empty state. A second truck would say there are two kinds of purchase order.
