{% comment %} A clickable, server-sorted table header cell. The reusable half of the sortable-header pattern; the data half is core.querystrings.sort_header(). Usage: {% include "partials/_sort_th.html" with col=cols.0 %} {% include "partials/_sort_th.html" with col=cols.2 cls="num" %} col a dict from sort_header() — label, href (bare query string), active, direction ("asc" / "desc" / None) cls optional class for the (e.g. "num" to right-align a money column) anchor optional element id; appended as #anchor so the full-page reload lands back on that card instead of the top of the page Every sortable header always shows one stroke-based chevron icon (.th-sort-icon, 12px, 1.5 stroke, same family in every state): idle = both chevrons in light grey; active = only the chevron for the current direction (up = ascending, down = descending) in the accent colour. The two chevrons keep fixed positions, so a state change only drops one and recolours — it never looks like a different icon. Non-sortable columns do not use this partial, so they show none. The link is "?"-relative, so it keeps the current path and replaces only the query string the view built. aria-sort is set on the active column only. {% endcomment %} {{ col.label }}
