{% load flash %}{% comment %} The result of an action, as a modal — success, error, warning or info. Default: renders the Django messages for this request. Pass `flash_source` (a list of strings) and `level` to raise the same modal for something that is not in the messages framework, e.g. the errors a form re-render carries: {% include "partials/_flash_modal.html" with flash_source=pos_errors level="error" %} The parameter is deliberately not called `items`: this partial is included from the base template on every page, and pages such as the order detail already put their own `items` (the order lines) in the context. One modal per include, however many messages there are: they are listed in it and headed by the most serious level, so a save that reports three things is one thing to dismiss, not three stacked dialogs. static/js/bottom-sheet.js opens it (data-autoshow), traps focus in it and removes it on dismiss. The panel is named with aria-label rather than aria-labelledby on purpose: a page can render this twice (messages plus its own errors), and two elements cannot share an id. Error takes role=alertdialog (interrupt: something needs fixing), everything else role=dialog. {% endcomment %}{% with flash_items=flash_source|default:messages %}{% if flash_items %}{% flash_summary flash_items level as flash %}
