{% comment %} The one KPI card (DESIGN.md §Components), the same row Floor Stock, Stock Adjustments and the Reports tabs carry — .label then .value, no inline tints. This row used to be three permanently-painted .stat tiles: green, amber and red side by side, on every load. Two things were wrong with that. Colour was carrying category rather than status, so a warehouse with nothing wrong still showed a red "Critical" panel and the palette stopped meaning anything; and "In Stock" was painted the same green the Status column uses for a healthy row, which made a count of zero look like a pass. Tint is now gated on a non-zero count, so an all-clear warehouse is plain white cards. In Stock takes no tint at all: it is the healthy figure, and there is no ok modifier on a KPI card precisely because "how many things are fine" is not a state anyone acts on. Low is .warn (act soon), Critical and No Stock share .danger (act now, No Stock just worse) — the same tints the Status column's pills use directly below. Thresholds (and the shared function computing all four tiers for both this page and Floor Stock) live in inventory.alerts.stock_status(). .compact because this row heads a dense table rather than a page. {% endcomment %}
