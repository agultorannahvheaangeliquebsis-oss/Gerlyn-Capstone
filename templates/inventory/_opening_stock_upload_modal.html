Import Opening Stock

Load inventory that already existed at the branches before this system went live.

Required columns: Barcode, Branch, and Opening Qty. Optional columns: Lot/Batch, Expiry Date, and Received Date.

Products must already exist in Product Master. Branch names must exactly identify one existing branch. Preview does not modify inventory. Download the template to start from the right columns.
