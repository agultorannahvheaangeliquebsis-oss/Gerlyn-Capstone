{% comment %} The one KPI card (DESIGN.md §2) — the same component as the Dashboard rail and the four Reports tabs, not a third lookalike. `.stat` is the quiet tile for secondary figures; these are the headline of the page, so they take the card. Reading order is .label → .value, so the figure is named before it is read, rather than after it as it was here. Tint is status, never category. gerlyn.css reserves .warn for "waiting on someone" and .danger for "act now", so both are gated on the count being non-zero: a branch with nothing wrong used to render an amber "Low Stock 0" and a red "Critical 0", a traffic light that lit up the same way no matter what the stock was doing. Colour now only appears when someone has to act on it, and it matches the .pill-warn/.pill-danger already in the Status column below. No Stock reuses .danger rather than inventing a fifth tint — it's still squarely "act now", just a worse case of it than Critical. In Stock takes no tint at all — there is no .ok card variant, because green is the Dashboard's selected-card colour and giving it a fourth meaning here is the thing that rule exists to prevent. No sub-text under the figures, by request. The thresholds these buckets are computed from (reorder_level is the Critical/Low Stock line; Low Stock runs up to 110% of it) are consequently not stated anywhere on this page — the Status column shows each row's verdict, not the rule behind it. The rule lives in inventory.alerts.stock_status(), shared with Warehouse Stock's identical row. .compact because this row heads a table, not a graph panel, and four cards across the full width leave the default block padding as empty card. {% endcomment %}
