{% comment %} The two tax/discount toggles, shared by the Add and Edit Product modals. Parameters: which "add" or "edit"; every element id is built from it is_vat_exempt current/posted value is_pwd_senior_eligible current/posted value fresh True only for a never-submitted Add form, where the eligibility box defaults to ticked Why `fresh` exists: an unticked checkbox posts NOTHING, so on a redisplayed form "no value" means the user unticked it — not "use the default". Defaulting to ticked on every render would make the box impossible to turn off on a form that failed validation. The view applies the same rule server-side. {% endcomment %}
