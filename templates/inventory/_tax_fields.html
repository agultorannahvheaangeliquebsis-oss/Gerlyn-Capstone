{% comment %} The tax/discount toggles, shared by the Add and Edit Product modals. Parameters: which "add" or "edit"; every element id is built from it is_vat_exempt current/posted value is_pwd_eligible current/posted value is_senior_eligible current/posted value PWD and Senior Citizen get their own box because they are separate statutes (RA 10754 and RA 9994) with separate exclusion lists — a product can qualify for one and not the other. Every box starts UNTICKED, on Add and on redisplay alike. An unticked checkbox posts nothing, so "no value" always means "not ticked"; with no default to preserve, the posted data is the whole truth about what the user chose. The view applies the same rule server-side. {% endcomment %}
